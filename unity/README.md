# unity/

C# side of the Unity Migration (`docs/profitable-unity-migration-gdd.md`). New, additive work in a separate project — does not modify the existing TypeScript/Phaser/Electron build (`src/`, `content/`, etc.), which stays live and deployable throughout the migration.

Through Migration Phase 1 Agents 31-34 (Data Schema, Simulation Core, Parity Validation, Infrastructure Adapters), this was a plain .NET solution with no Unity install required. **Unity Editor dependency begins at Agent 35** (Unity MVP Presentation) — the real project lives at `ProfitableUnity/` (Unity 6000.5.6f1). Setting up the Editor itself was a manual, interactive process (Unity Hub install, account login, license activation) — see `UNITY_EDITOR_SETUP.md` for the step-by-step guide that was used.

## Structure

- `ProfitableUnityMigration.sln` — solution file.
- `ProfitableCore/` — class library (targets `netstandard2.1` for future Unity scripting-runtime compatibility):
  - `Schema/` — ported types and `QualityMap`/`QualityAverageMap` (`docs/agents/agent-31-unity-data-schema.md`, `agent-32-unity-simulation-core.md`).
  - `Constants/` — the five MVP constant tables (`agent-31-unity-data-schema.md`).
  - `Content/` — `ContentLoader`, parsing the real `content/*.json` files as-is (`agent-31-unity-data-schema.md`).
  - `Simulation/` — ported formula logic: `RollQuality`, `TierColorResolver.GetTierColor`, `Refiner.Refine`, `Crafter.Craft`, and their supporting lookups (`agent-32-unity-simulation-core.md`).
  - `Adapters/` — `ISaveSystem`/`FileSaveSystem`, `IAudioManager`/`RegistryAudioManager` (`agent-34-unity-infrastructure-adapters.md`).
- `ProfitableCore.Tests/` — xUnit test project (`net8.0`):
  - `Fixtures/` — copies of the real `content/*.json` files, used to prove `ContentLoader` parses actual current content, not synthetic data — see that folder's own README for the re-copy-when-stale caveat.
  - `Simulation/`, `Adapters/` — unit tests mirroring the TypeScript test suites case-for-case.
  - `Parity/` — reads `../parity/ts-parity-results.json` and re-runs it through the C# port, asserting exact equality against the real, executed TypeScript output (`agent-33-unity-parity-validation.md`).
- `parity/ts-parity-results.json` — the parity corpus, generated by `npm run parity` (`scripts/parityHarness.ts`) from the repo root. Regenerate and re-run `dotnet test` if `src/simulation/*.ts` changes.
- `ProfitableUnity/` — the real Unity project (Editor 6000.5.6f1). See `agent-35-unity-mvp-presentation.md` for the full contract; briefly:
  - `Assets/Plugins/` — `ProfitableCore.dll` (built via `dotnet build -c Release`) plus its NuGet dependency DLLs, copied in as Unity plugin assemblies — not source-embedded, so `ProfitableCore`'s own independent `dotnet build`/`dotnet test` flow stays untouched.
  - `Assets/StreamingAssets/Content/` — copies of the real `content/*.json` files, read at runtime by `GameContent.cs`. Same re-copy-when-stale caveat as `ProfitableCore.Tests/Fixtures/`.
  - `Assets/Scripts/` — the presentation layer (`Content/`, `UI/`), all UI built in code rather than hand-placed in the Editor (no Unity MCP tooling available this session — see the contract's Design decisions).
  - `Assets/Scenes/MvpLoop.unity` — one scene, four panels (Map/Gather/Refine/Craft) toggled by a shared nav bar, built via `Assets/Editor/SceneBuilder.cs` (`-executeMethod`) rather than hand-authored YAML.
  - `Assets/Tests/EditMode/`, `Assets/Tests/PlayMode/` — Unity Test Framework tests, run via `Unity.exe -batchmode -runTests -testPlatform <EditMode|PlayMode>` (note: no `-quit` — it conflicts with `-runTests` and silently skips the test run).

## Running

```
cd unity
dotnet build
dotnet test
```

Unity tests (from a shell, `Unity.exe` path will vary by install):
```
Unity.exe -batchmode -nographics -projectPath unity/ProfitableUnity -runTests -testPlatform EditMode -testResults <path>.xml -logFile <path>.log
Unity.exe -batchmode -nographics -projectPath unity/ProfitableUnity -runTests -testPlatform PlayMode -testResults <path>.xml -logFile <path>.log
```

**Sub-Phase D (Ships & Travel, incl. Full verification sweep: `dotnet test` 743/743, Unity EditMode 55/55, Unity PlayMode 2/2, `npm test` 687/687.
